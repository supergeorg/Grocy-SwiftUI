This is just a small update, but it brings support for new versions of Grocy as well as iOS.

- Support Grocy up to version 4.7.1
- Fix some data parsing problems
- Add a badge to show how many filters are applied
- Build with support for iOS 27
- New widgets for the shopping list, chores and tasks, also on the Lock Screen
- The stock widget works better with VoiceOver, larger text and tinted Home Screens
