This is one of the biggest updates for Grocy functionality-wise ever! I call it the recipe update. As you may have guessed, this update brings support for recipes to Grocy Mobile.
With this you can view existing recipes as well as create new ones. It is possible to add ingredients to a recipe, add subrecipes and edit the preparation by using an integrated WYSIWYG HTML editor.
This is the first version of the recipe feature, so some improvements will be made to it.

There are also some small features, like that the sorting should be saved in most views.

A small sneek peek on the next feature: I am trying to add a parser using Apple Intelligence to get recipes automatically from a website.

Changes:
- New recipe feature
- Sorting is saved in some views
- Small bug fixes (and another try at the CoreData bug)

Dies ist eines der größten Updates für Grocy Mobile vom Funktionsumfang her! Ich nenne es das Rezept-Update. Wie man darauf schließen kann, bringt dieses die Rezept-Funktionalität nach Grocy Mobile.
Mit diesem kann man existierende Rezepte anschauen sowie neue erstellen. Es ist möglich, Zutaten zu einem Rezept hinzuzufügen, Unterrezepte einzustellen und die Zubereitung mittels eines WYSIWYG HTML-Editors zu bearbeiten.
Dies ist die erste Version der Rezept-Funktion, daher kann sich noch einiges daran ändern.

Es gibt ein paar kleine weitere Änderungen, wie dass die Sortierung in einigen Ansichten gespeichert wird.

Eine kleine Vorschau auf das nächste Feature: Ich versuche einen Parser mit Apple Intelligence zu bauen, welcher Rezepte aus einer Website holt.

Änderungen:
- Rezept-Funktionalität
- Sortierung wird in einigen Ansichten gespeichert
- kleinere Fehlerbehebungen (und ein weiterer Versuch, das CoreData-Problem zu beheben)
