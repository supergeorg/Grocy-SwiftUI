This is a small bugfix update for Grocy Mobile.

It contains no new features, but should fix multiple small issues and crashes.

Changes:
- Small graphic fixes and changes (Sidebar, Text field, Server Selection)
- Fix crashes for specific system time formats
- Show non-provided dates for stock as never overdue
- Show stock elements with no own stock but accumulated stock
- Allow unsafe connections for ts.net (Tailscale) domains, since these are local

Dies ist ein kleines Fehlerbehebungs-Update für Grocy Mobile.

Es enthält keine neuen Features, sollte aber mehrere kleine Probleme und Abstürze beheben.

Änderungen:
- Kleinere graphische Verbesserungen und Änderungen (Seitenleiste, Text-Feld, Server-Auswahl)
- Behebung von Abstürzen für bestimmte System-Zeitformate
- Zeige nicht-gegebene Daten für Bestand als nicht ablaufend an
- Zeige Bestandselemente ohne eigenen Bestand aber mit akkumulierten Bestand an
- Erlaube unsichere Verbindungen für ts.net (Tailscale) Addressen, da diese wie lokal zu betrachten sind
