3.0.1

This is the first update for Grocy Mobile 3.0, the new version with Liquid Glass design and a multitude of changes.

The new data structure allows for a quite simple implementation of the first widget for the app. It shows the current volatile stock count (due soon, overdue, expired, below min stock). It is available in 3 sizes, and on medium and large the filter gets applied to stock view when you click on it.

Another feature was in a semi-ready state for more than 3 years: Reminders integration. This is only the first stage of the implementation, it allows to export a shopping list to the Reminders app. Just tap on the shopping list menu, select export to Reminders and confirm. Import is not fully implemented yet and will take some time.

Additionally, some bugs should be fixed, namely the error with external Barcode lookup and hopefully some part of the factored amount.

Changes:
- Widget for volatile stock
- Reminders export
- Bugfixes

Dies ist das erste Update für Grocy Mobile 3.0, die neue Version mit Liquid Glass-Design und vielen Änderungen.

Die neue Datenstruktur erlaubt eine relativ einfache Implementierung des ersten Widgets für die App. Dieses Zeit die Menge des aktuell relevanten Bestands an (bald fällig, überfällig, abgelaufen, unter Mindestbestand). Es ist in 3 Größen erhältlich, auf Mittel und Groß wird der Filter für den Bestand angewendet, wenn man darauf klickt.

Ein weiteres Feature lag mehr als 3 Jahre halbfertig herum: die Integration in Erinnerungen. Dies ist die erste Stufe der Integration und erlaubt einen Export der aktuellen Einkaufsliste in die Erinnerungen-App. Drücke auf den Namen der Einkaufsliste, wähle den Export aus und bestätige. Ein Import ist noch nicht da und wird auch etwas dauern.

Weiterhin sollten einige Bugs gefixt sein, insbesondere das Problem mit der externen Barcode-Suche und faktorisierten Mengen.

Änderungen:
- Widget für aktuellen Bestand
- Erinnerungen Export
- Fehlerbehebungen
